# hao-backprop-test
Test project for backprop integration (Python 3 / Flask). Do not touch!

## Getting Started

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the server

```bash
python app.py
```

The server runs at [http://127.0.0.1:3000/](http://127.0.0.1:3000/).
